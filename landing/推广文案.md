## 1. 知乎（回答贴 / 专栏）

**标题（备选）**

1. 有没有能自动答超星学习通题目的脚本？实测这个还行
2. 超星学习通刷课工具对比：D-Whaler 用了两周，说点真实体验

**正文**

```
写点真实体验，攒了好几天。

我用的是 D-Whaler（v0.5.2，MIT 开源），装在脚本猫上，右下角一个面板，
学习通页面打开就生效。目前主要用这几个功能：

· AI 自动答题 —— 接DeepSeek，单选多选判断填空都能做。
  它不是只问一遍：答不出来会自动重问，最多 3 遍，连续失败就跳过这题
  继续下一道。这个设计挺关键，否则一道题能把整条流程卡死。

· 视频倍速 + 卡顿自愈 —— 倍速播放，遇到播放器停顿会自动戳一下重播。
  处于答题暂停状态的视频不会被抢播。

· 字体解密 —— 学习通那个加密字体解开，复制和搜题不乱码了。

· API 花费可视化 —— 这个是我最喜欢的。用 DeepSeek 之前我根本不知道
  一次章节测验要烧多少钱。它把请求数、token、预估花费直接显示在面板上，
  还能看到账户余额，并且区分「本次」和「累计」，点一下就归零。

界面是真的好看，液态玻璃那种感觉，设置项藏得挺深但不难找。

说几个我觉得需要注意的地方：

1. 只适配了 Edge。我用 Chrome 试过，报错，不过作者说明写了这一点。
2. 安装范围只覆盖 4 个站点（chaoxing + 3 个学校自己的慕课平台），
   不是所有 edu.cn。你学校如果用的是别的域名，得看作者后续更新。
3. AI 答题要自己填 DeepSeek 的 API Key，费用按 DeepSeek 官方收，
   不免费。花多少自己心里有个数。

关于「刷课」这事我多说一句：这脚本定位是学习辅助，能省掉很多重复点击，
但学校对在线学习是有考核要求的，用不用、怎么用，你自己判断，
风险自负。脚本里也写了这条声明，我觉得作者态度挺规矩的。

项目开源在 GitHub（https://github.com/Dream-Architect1026/D-Whaler），MIT 协议，有问题可以去 issues 提。
版本更新比较勤，我这两周用下来已经从 0.4.11 升到 0.5.2 了。

仅供个人学习与研究使用，别用来替考或者代写作业。
```

## 4. V2EX / NodeSeek / 即刻（技术向）

**标题**

```
[开源] D-Whaler — 超星学习通学习辅助脚本 v0.5.2
```

**正文**

```
自写的一个油猴脚本，开源 MIT，欢迎提 issue。

D-Whaler v0.5.2 · 超星学习通学习辅助

技术上几个点：
· Vue 3 + Element Plus + Pinia，打包成单文件 userscript
· 字体解密走 ttf 映射表还原
· AI 答题接 DeepSeek 官方 API，答案按「字母索引 + 文本相似度」
  双通道定位回填，兼容 B / A,C / 全角 Ｂ 等多种返回写法
· 0.5.2 加了自动重问（最多 3 遍），避免单题把流水线卡死
· API 花费做了分峰谷计价（MODEL_PRICES），面板实时显示

几个踩过的坑，供参考：
· 「本次」用量归零失灵的根因是基线写在 sessionStorage，
  它在同一标签页跨刷新/关脚本重开都存活 ⇒ 改内存变量（0.4.12 修复）
· 面板双挂载的根因是旧版宿主是无属性裸 div 且无去重保护，
  新旧同时存在时旧面板压在新上面，表现为「代码改了界面没变」（0.4.0 修复）
· el-tab-pane 未激活时 display:none，scrollHeight 为 0，
  日志自动贴底必须在切页可见之后再补几拍滚动

仓库：https://github.com/Dream-Architect1026/D-Whaler
仅供个人学习与研究使用。
```
