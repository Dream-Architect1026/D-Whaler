## 三、⚠️ 已知需要处置的风险点

### 1. 第三方字体表依赖（最需要关注）

```
@resource ttf https://www.forestpolice.org/ttf/2.0/table.json
```

- 这是字体解密用的 ttf 映射表，但托管在**林业站点**上，与项目本身毫无关系。
- 双重风险：① 该站点一旦改路径/下线，**字体解密静默失效**；② 审核时容易被追问「为什么依赖一个不相关的外部域名」。
- 建议二选一：
  - **方案 A（推荐）**：把 `table.json` 存进你自己的仓库，改成 `@resource ttf https://raw.githubusercontent.com/Dream-Architect1026/D-Whaler/main/assets/table.json`
  - **方案 B**：保留原URL，但准备好被驳回后改动的准备。
  - 无论哪种，都请实测一次字体解密是否正常。

### 2. `data:` 形式的 `@require`

```
@require data:application/javascript,window.Vue%3DVue%3B
```

部分脚本管理器对 `data:` URI 的 `@require` 支持不一致。若脚本猫安装后报 `Vue is not defined`，删掉这一行即可（前面已引入 Vue 全局包）。

### 3. 两个 Element Plus 版本并存

```
@resource ElementPlus      .../element-plus/2.7.2/index.css
@resource ElementPlusStyle .../element-plus/2.8.2/index.min.css
```

2.7.2 的 JS 配 2.8.2 的 CSS。当前能跑，但版本不一致是隐患，建议统一到同一版本。

### 4. 行尾为 LF

当前纯 LF（`CRLF=0`）。已在 `.gitattributes` 里用 `*.user.js -text` 锁死，防止 git 转换。若你的发布渠道要求 CRLF，需在打包时单独转换并在 README 说明。
